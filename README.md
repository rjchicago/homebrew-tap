# Homebrew Tap

Custom Homebrew tap by [rjchicago](https://github.com/rjchicago).

## Install

```bash
brew tap rjchicago/tap
brew install termv
```

## Formulas

| Formula | Description |
|---------|-------------|
| [termv](https://github.com/rjchicago/termv) | Terminal Velocity - a high-performance terminal-based game |

## Upgrade

```bash
brew upgrade termv
```

## Uninstall

```bash
brew uninstall termv
brew untap rjchicago/tap
```
